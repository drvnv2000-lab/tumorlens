# Data in this folder

Derived from the LUMIERE dataset (Suter et al., Scientific Data 9, 768, 2022; https://doi.org/10.6084/m9.figshare.c.5904905.v1). The data descriptor states that the dataset may only be used for non-commercial purposes; TumorLens follows that condition. These slices and numbers are NOT covered by the repository's MIT licence. Not for clinical use.
